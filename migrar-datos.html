Migración de registros antiguos

Esta herramienta importa una copia JSON de la versión local antigua de Iglesia Renacer hacia la base de datos Supabase.

Verificando sesión y permisos de administrador…
Antes de continuar: selecciona el archivo JSON de respaldo que exportaste desde la versión antigua. Se migrarán miembros, peticiones y notas pastorales. Las cuentas y contraseñas antiguas se ignoran expresamente.
Opción A — este navegador: lee los registros antiguos que todavía estén guardados localmente en este mismo navegador y dominio.

Los datos locales de otros computadores o celulares no se comparten. Repite este proceso en cada dispositivo que tenga registros antiguos, o usa un respaldo JSON.
